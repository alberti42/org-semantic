First release.

Two indexes over a tree of org notes, searched separately: a semantic one that
finds notes by meaning, and a lexical one that finds them by word. One static
binary, no database, no Python.

An Emacs client ships with it — `org-semantic-find` for a results buffer, and a
`serve` process that keeps the model resident so a warm query is about 9 ms.

**macOS:** the binary is Developer ID signed and notarized. Apple Silicon only —
`ort` publishes no prebuilt ONNX Runtime for Intel macOS.

**Windows:** built by CI and not otherwise tested.
